# PLOS Computational Biology Education submission checklist

## Manuscript

- [x] Separate Quick Tips manuscript created.
- [x] Seven declarative tips arranged as a workflow.
- [x] Adjacent guidance cited and contribution distinguished.
- [x] Original summary figure, caption, and alt text included.
- [x] No segmentation-performance, biological-effect, usability, or learner-outcomes claim.
- [x] Confirm manuscript is approximately 2,000 words and below the 2,500-word ceiling.
- [ ] Replace the current archive citation with a v0.2.0 version DOI after freezing the submitted companion resource.

## Author metadata to confirm

- [ ] Corresponding-author email.
- [ ] ORCID.
- [ ] Final affiliation and location.
- [ ] Short running title.
- [ ] CRediT author-contribution roles.
- [ ] Funding statement.
- [ ] Competing-interests statement.
- [ ] Acknowledgements, or confirmation that there are none.
- [ ] Confirm the wording and level of detail in the AI-use disclosure.

## Submission system

- [ ] Select article type `Education`.
- [ ] Select section `General`.
- [ ] Upload the manuscript PDF and original figure file.
- [ ] Enter data and code availability with GitHub and the v0.2.0 DOI.
- [ ] Prepare a 150-200 word plain-language Author Summary in case the system requests one for this article type.
- [ ] Suggest five or six independent reviewers with relevant bioimage-analysis, quantitative-methods, or computational-education expertise.
- [ ] Exclude recent collaborators, people at the same institution, and anyone with another relevant conflict.

PLOS currently states that it does not accept presubmission enquiries. Submit the complete manuscript directly when these checks are complete.
