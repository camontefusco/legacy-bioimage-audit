## Important discrepancy

Rerunning `04_quantification_backup.ipynb` did not reproduce its archived `fig34_image_level_quantification.csv` byte-for-byte. Several panels changed slightly in segmented area or object count. For example, panel A changed from 58 to 60 objects and panel J from 84 to 85 objects. Other panels were unchanged.

The most likely explanation is that the archived Notebook 04 table was generated by an earlier state of the exploratory notebook and the notebook was edited afterward without regenerating every saved output. Notebook 05 does not show this problem and is therefore the canonical reproducible pipeline.

The manuscript and downstream paper figures use the Notebook 04 table, whereas the independently reproducible batch table is produced by Notebook 05. These two analysis branches must be reconciled before public release or resubmission.

## Method actually implemented

The canonical `src.segmentation.segment_objects` implementation performs:

1. Green-channel extraction
2. Gaussian smoothing
3. Morphological-opening background estimation and subtraction
4. Normalization
5. Otsu thresholding
6. Small-object removal
7. Binary closing
8. Distance transform and watershed separation

Notebook 05 calls this implementation with `min_size=8`, `gaussian_sigma=0.8`, and `background_radius=25`.

## Publication status

The recovered project establishes computational provenance for the submitted numbers, but it does not resolve the reviewers' experimental-design objections. The inputs remain screenshot-derived thesis panels with one image per condition and no independent biological replication.

Before creating a public repository, choose one canonical analysis branch, regenerate every table and figure from that branch, remove stale outputs, record exact package versions, add automated checks, and align the manuscript methods and results with the regenerated artifacts.
