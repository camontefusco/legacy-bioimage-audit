# Small teaching pilot

## Purpose

This pilot tests whether learners can use the module, understand its claim boundaries, and complete the core audit tasks. It does **not** test biological effectiveness or establish formal educational efficacy.

## Recommended format

- Participants: 3–5 adults with basic scientific or Python familiarity.
- Duration: 60–90 minutes.
- Mode: remote screen-sharing or an in-person computer session.
- Repository version: record the exact commit before starting.
- Data: use only the included synthetic panels.

## Files

- `invitation.md`: text for recruiting learners.
- `facilitator-guide.md`: preparation, timing, observation, and close-out.
- `learner-worksheet.md`: tasks and interpretation prompts.
- `feedback-form.md`: short post-session questionnaire.
- `session-record.md`: anonymized session-level results and revision log.

## Minimum completion rule

The pilot is complete when at least three learners have attempted the module and the facilitator has recorded:

1. approximate completion times;
2. installation or execution failures;
3. answers to the five core understanding questions;
4. recurrent points of confusion; and
5. repository revisions made in response.

Do not report success percentages as generalizable educational outcomes. With 3–5 learners, use counts and descriptive language only.
