# Invitation text

Would you be willing to test a short open teaching module about auditing legacy bioimage analyses?

The exercise uses synthetic fluorescence-like images and a Jupyter notebook. It teaches how preprocessing and segmentation choices affect measurements, why agreement is not the same as accuracy, and when missing raw data or replication should stop biological interpretation.

- Time: approximately 60–90 minutes
- Format: [remote / in person]
- Preparation: a laptop with Python 3.10 or newer, or attendance at a facilitated shared-computer session
- Prior experience: basic Python or scientific-computing familiarity is helpful but not essential

Participation is voluntary. We will record only session-level observations and anonymous answers; no sensitive personal data or biological images will be collected. Feedback will be used to improve the public learning resource.
